# Release Note

## Phiên bản v1.0

- **Ngày phát hành:** 05/11/2026

### Chức năng mới

- Xây dựng trang CV cá nhân bằng HTML5 và CSS3.
- Thêm phần giới thiệu, kỹ năng, dự án tiêu biểu và thông tin liên hệ.
- Bố cục responsive với menu điều hướng, lưới kỹ năng và lưới dự án.
- Thêm hình ảnh đại diện và hình minh họa cho các dự án.
- Bổ sung tài liệu mô tả dự án, yêu cầu môi trường, cấu hình và hướng dẫn chạy trên Windows, macOS, Linux, Docker.

### Lỗi đã sửa

- Hoàn thiện cấu trúc phân chia các phần trong trang bằng các thẻ HTML ngữ nghĩa.
- Điều chỉnh bố cục CSS để trang hiển thị phù hợp trên nhiều kích thước màn hình.

### Hạn chế còn tồn tại

- Trang chủ yếu sử dụng nội dung tĩnh; chưa có chức năng xử lý dữ liệu bằng JavaScript.
- Một số liên kết GitHub và LinkedIn chưa có địa chỉ đầy đủ.
- Một số liên kết xem chi tiết dự án chưa được triển khai.
